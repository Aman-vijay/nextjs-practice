# Team Management

A fresh Next.js project.

## Getting Started

Install dependencies:
```bash
npm install
# or
bun install
# or
pnpm install
```

Run the development server:
```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to see your app.

## Project Structure

- `app/` - App router and pages
- `public/` - Static files
